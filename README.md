SmartNutriTracker – Equipo 6

Módulo de Notificaciones y Testing

Descripción

El Equipo 6 es responsable del módulo de Notificaciones y Testing del sistema SmartNutriTracker, una aplicación orientada al seguimiento y gestión de hábitos nutricionales.

Este módulo permite mantener informados a los usuarios mediante notificaciones internas, generar alertas sobre hábitos no saludables y registrar eventos del sistema para facilitar su supervisión y mantenimiento.

Objetivo

Desarrollar funcionalidades de notificación, registro de eventos y documentación técnica que permitan mejorar la comunicación con los usuarios, facilitar el seguimiento de hábitos nutricionales y mejorar el control del funcionamiento del sistema.

Historias de usuario

HU-27 – Alertas de hábitos no saludables

Como docente, quiero recibir alertas si un estudiante supera determinados límites nutricionales, para intervenir oportunamente.

HU-28 – Notificaciones internas

Como usuario, quiero recibir recordatorios diarios, para mantener el registro de mis hábitos.

HU-29 – Configuración de logs globales

Como desarrollador, quiero implementar registros de errores y acciones, para mejorar la trazabilidad del sistema.

HU-32 – Documentación con Swagger

Como usuario técnico, quiero visualizar la API con Swagger, para entender cómo consumir los endpoints.

Funcionalidades principales

- Generación de alertas sobre hábitos nutricionales no saludables.
- Notificaciones internas para los usuarios.
- Recordatorios diarios.
- Registro de errores y acciones del sistema.
- Configuración de logs globales.
- Seguimiento de eventos para mejorar la trazabilidad.
- Documentación y visualización de endpoints mediante Swagger.
- Verificación del funcionamiento del módulo.

Tecnologías utilizadas

- Blazor: desarrollo de la interfaz de usuario y aplicación web.
- Visual Studio: entorno de desarrollo del proyecto.
- SQL Sereer: sistema de gestión de base de datos.
- Swagger: documentación y visualización de los servicios API.
- Git y GitHub: control de versiones y gestión del código fuente.

Integración con el sistema

El módulo de Notificaciones y Testing forma parte de SmartNutriTracker y se integra con los demás módulos de la aplicación para facilitar la comunicación con los usuarios, gestionar alertas nutricionales y mejorar el seguimiento de las actividades del sistema.
